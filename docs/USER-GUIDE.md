## 这个工具想让你做什么

把一期德语新闻切成几十段，每段十几秒。你对着一段：

**听清 → （写下来）→ 看着原文再听 → 说一遍 → 听自己说的**

然后进下一段。练的是「听清」到「说出」这条链路——不是背单词，也不是读课文。

三件事它**故意不做**，知道了才不会找：

| 不做 | 为什么 |
|---|---|
| 判听写对错 | 不 diff、不高亮、不算分。你写的和原文上下叠、同宽同字号，**写错的地方从那儿开始错位**——错位本身就是信号，它是排版的自然结果，不是标记 |
| 评发音 | 录音只给你自己听。机器打分会把注意力从「说清楚」引到「凑分数」 |
| 记录学习进度 | 没有连续天数、没有完成率。它是工具不是打卡应用 |

## 导入一期素材

界面右上角 **＋** → 粘贴链接 → **导入**。

**推荐 ZDF 的 logo!**：到 https://www.logo.de/ 找按日期命名的整期，链接形如
`https://www.logo.de/logo-vom-freitag-21-august-2026-100.html`。
选它是因为**它有官方德语字幕**——机器转写会把德语复合词拆错
（`Dopingkontrolle` → `Doping Kontrolle`），对学德语的人是实害。
有官方字幕就不用转写，拼写 100% 正确，而且快得多。

别的站点也行，底层是 yt-dlp，YouTube、ARD 都能抓，没有字幕的会自动转写。

### 点了导入之后

会**卡 1–3 秒**，然后回显标题和时长：

```
logo! vom Freitag, 21. August 2026 · 08:11 —— 已加入队列。
```

这一卡是有意的——它在实时去问那个网站。这几秒换来的是：链接贴错了当场就知道，
不用等三分钟才发现。回显的标题和时长就是确认贴对没有的依据。

### 出错的话

四种失败分开说，因为你的下一步完全不同：

| 提示 | 你该做什么 |
|---|---|
| 这不像一个网址，检查是否漏了 https:// | 补上协议头 |
| 这个站点抓不了 | 换个站点 |
| 这个视频已经不在了 | 换个视频 |
| 这个视频在当前网络下看不到，可能有地域限制 | 配代理（见 README） |
| 这个视频需要登录才能看 | 放弃这条 |
| 这是纯音频，暂时不支持 | 回声闭环要画面配合，换有画面的 |

### 处理要多久

一期 8 分钟约 5 分钟，**绝大部分时间在下载**。四个阶段：

```
下载 → 转码 → 转写 → 生成章节与翻译
```

首页会显示进度条和当前阶段。前三个阶段有真实百分比，最后一步是转圈——
LLM 调用没有可观测的进度，编一个百分比出来只会在 87% 卡住三十秒。

**转写一完成就能开练**，不用等章节和翻译。素材会变成「可跟读」状态，
章节位置显示「章节生成中 · 跟读现在就能用」。

## 首页

```
┌──────────────────────────────────────────────────────┐
│ ┌────────┐  2026-08-21  自导入                        │
│ │ 缩略图 │  logo! vom Freitag, 21. August 2026        │
│ │  08:11 │                             [▶ 开始跟读]   │
│ └────────┘                                            │
├──────────────────────────────────────────────────────┤
│  01  Yasuní-Nationalpark              2:08   ▶       │
│  02  Doping im Sport                  2:51   ▶       │
└──────────────────────────────────────────────────────┘
```

最新一期展开成大卡片，往期是紧凑行。订阅源和自己导入的**混在同一条时间线**，
只用徽章区分——青绿的是订阅源（删不掉，要取消订阅），灰的是自己导入的（能删）。

**点哪里都是直接开练**：封面、标题、「开始跟读」、任意章节、任意往期行。
点章节会直达那一章的第一段。

首页**只谈时长不谈段数**。决定「今天练哪条」靠的是「这条要花几分钟」，
段数是内部结构，它只在跟读时作为进度指示（`#11 / 53`）出现。

处理中和失败的素材插在中间。失败的那条有两个按钮：**从该步重试**
（已完成的阶段不重跑，几百 MB 的视频不会重下）和**仍然进入**
（生成章节翻译失败不阻塞跟读，转写完成的话段落照样能练）。

## 回声闭环：五个步骤

进去之后是这样：

```
┌────────────────────────────────────────────┐
│              视频画面          0:41 / 8:11 │
└────────────────────────────────────────────┘
 ▪▪ ▪▪ ▪▪▪ ▬▬▬▮ ▫▫ ▫▫▫ ▫▫ …          ← 段落进度条
        Extrem starker Regen …             ← 字幕区
    ● 播放原声  ○ 听写  ○ 录音与回放         ← 阶段条
           到段尾自动暂停
 [↺ 再听原声 Space] [←上一段] [下一段→]      ← 控制条
```

### ① 播放原声

进来自动开播，**到段尾自动暂停，画面停在那一帧**——不黑屏、不跳回开头。

字幕区默认空着。想看按 `S`。

### ② 听写（默认关）

只有在设置里打开才有这一步。

**写作时原文和翻译都不可见，这一步也不提供 `S`**——看到原文等于直接看答案。
听不清就按 `Space` 再听一遍，听多少遍都行。

写完按 `Enter` 提交，**提交即自动展示对照**，不用再点一次：

```
我写的
┌──────────────────────────────────────────┐
│ Doch obwohl das alles so wunderschön     │
│ aussieht und klingt - es gibt einen      │
│ Haken.                                   │
└──────────────────────────────────────────┘
原文
┌──────────────────────────────────────────┐
│ Doch obwohl das alles so wunderschön     │
│ aussieht und klingt - es gibt einen      │
│ Haken. Und genau über diesen "Haken"     │  ← 从这里开始你没写
│ regen sie sich hier gerade richtig auf.  │
└──────────────────────────────────────────┘
```

两块同宽、同字号、同行高。**相同的词自动垂直对齐，写错或漏掉的地方从那儿开始错位。**
没有高亮、没有删除线、没有分数——你自己一眼就看得见差在哪。

不满意按 **✎ 重写**，已输入的内容保留。满意按 `Enter` 继续。

### ③ 二次播放 + 展示原文

重听一遍，这次**看着原文**听。它跟着「录音与回放」这个开关走——
关掉录音就没有它，因为单独留着它等于「重听一遍然后什么也不做」。

播完自动进下一步。

### ④ 录音

视频四周出现**恒亮的青绿边框**，右下角正向计时 `3.4s`。

- **正向计时，没有倒计时**。倒计时会逼你赶时间，而这里要的是说清楚
- **不给任何参照值**。不告诉你原声多长——那会让你去凑时长，而不是去说清楚
- `Enter` 结束，或者 180 秒兜底自动结束
- **边框不闪不呼吸**。录音是持续状态不是事件，动起来只在余光里制造噪音

第一次会问麦克风权限。拒绝了的话会提示怎么恢复。

### ⑤ 回放

`Space` 就是「回放录音」。想听原声对比按 **▶ 原声**——**听完停在原地，不会往下走**。

这一步不给单独的「▶ 我的」按钮：那就是 `Space` 本身，两个入口做同一件事
只会让人怀疑它们不同。

### ⑥ 等待确认

**不自动推进。** 什么时候进下一段是你的决定。

这时候才同时给「▶ 原声」和「▶ 我的」，因为 `Space` 的语义已经变成「从头再来」。

你的录音**在这里就被释放了**——切段即刻销毁，不落盘、不上传、不留任何副本。

## 快捷键

这个工具是键盘优先的，鼠标是备选。

| 键 | 作用 |
|---|---|
| `Space` | **重复当前这一步**。五个步骤里含义各不相同，所以按钮文案会跟着变 |
| `Enter` | 结束录音 / 提交听写 / 继续 |
| `←` `→` | 上一段 / 下一段 |
| `S` | 字幕。**语义随步骤反转**：① 是「显示」，③④⑤ 是「隐藏」，② 不提供 |
| `T` | 中文翻译 |
| `Tab` | 段落侧栏 |
| `Esc` | 返回首页；侧栏开着时先收侧栏 |

**在听写输入框里打字时**，只有 `Enter` 和 `Esc` 生效，其余按键都归输入本身——
不然打 `s`、`t` 会触发字幕和翻译，而德语里这两个字母到处都是。

## 设置

顶栏 **⋯** 打开。改一次以后每期都是这样，存在浏览器本地。

```
回声环节
  00  全文播放                  ○━━
      ① 播完自动进下一段，一路连到全文结束，不进听写与录音
  01  播放原声                  始终
      到段尾自动暂停
  02  听写                      ○━━
      写完提交，就地展示答案
  03  录音与回放                ━━●
      录音前自动重听一遍并展示原文；录完立即回放对比
显示
  —   段落进度条                ━━●
      视频下方，点哪格跳哪段
```

几件值得知道的事：

**① 播放原声不能关。** 它是闭环的地基——一段没听过就没什么可跟读的。
既然关不掉就不给开关：一个能点但点了没意义的控件比不给更糟。

**「录音与回放」是一个开关管三步**（二次播放 → 录音 → 回放）。
二次播放是录音前的准备，回放是录音后的对比，两者都没有独立存在的理由。

**关掉的步骤完全跳过**，不会先闪一下再消失。全都关掉的话就退化成
「播放原声 + 等待确认」，闭环仍然成立，只是最短。

**改设置立刻生效，没有保存按钮，也不弹提示**——生效本身就是反馈。

## 两种别的用法

### 只想听一遍整期

打开 **00 全文播放**。① 播完不进下一步，而是**进下一段继续播 ①**，一路连到底。
状态行会写「连播中 · 播完自动进下一段」。

中途想认真练某一段，**按 `Enter` 就从连播里跳出来**进入这一段的听写／录音。

### 只想练某一段

三条路都行：

- 首页点章节 → 直达那一章第一段
- 回声页按 `Tab` 拉出右侧段落列表 → 点任意一段
- 视频下面的段落进度条 → 点任意一格

段落进度条是**按段导航，不是可拖动的播放条**。每格宽度按该段真实时长分配，
所以它顺带告诉你这期有多长、段落长短怎样、你在哪儿。

> 为什么不能自由拖动：闭环的每一步都要精确到段。拖到段中间之后，
> 按 `Space`「再听一遍」该从哪儿开始就说不清了。

## 常见疑问

**录音存在哪？**
不存。切到下一段的瞬间就销毁了，不落盘、不上传、离开页面即消失。
想留下来的话本期做不到。

**LLM 会看到我的视频和录音吗？**
不会。发给它的只有转写出来的**文字**，用来分章、拟标题、翻译。
音频和视频不出本机。

**为什么侧栏里能看到原文，听写时不是不给看吗？**
侧栏里的德语就是字幕，写作时它照常显示——**这是有意保留的「偷看」通道**。
听写本来就不判对错、不算分，产品既然不打算抓作弊，就没有把答案锁起来的立场。
不想看就按 `Tab` 把侧栏收起来，那是你自己的选择。

**没有章节，段落是平铺的？**
说明这期走了降级路径——没配 LLM key，或者 LLM 调用失败了。
**跟读不受影响**，只是没有章节标题和中文翻译。配上 key 重新导入即可（见 README）。

**为什么导入要卡几秒？**
它在实时去问那个网站要标题和时长。换来的是链接贴错当场就知道。

**能改每段多长吗？**
`.env` 里的 `CHUNK_TARGET_WORDS`，默认 22 词（实测平均 22.4 词 / 8.9 秒）。
改完对**新导入**的素材生效，已有的不会重切。

**视频拖不动 / 段落跳不准？**
不该发生。若真如此，多半是那期素材的转码出了问题，试试删掉重新导入。

## 已知限制

| | 说明 |
|---|---|
| **磁盘会被吃满** | 一期约 160 MB，每天一期约 1.1 GB/周。**清理功能本期没做**（`TASK-045`）。腾地方请用界面删除自行导入的素材——那条路会连数据库记录一起清掉；直接删目录会留下坏记录 |
| 只支持有画面的素材 | 纯音频在导入时就被拒。回声闭环的「画面跟随」对着一块黑屏无从谈起 |
| 单用户 | 没有登录，没有多人。这是自托管单人工具 |
| 详情页暂时不在动线上 | 页面还在，直接敲 `/episode/1` 能打开，但首页不再链向它 |
| 不记录进度 | 没有连续天数、没有完成率、没有「上次练到哪」 |
| 录音无法导出 | 见上，切段即销毁 |
